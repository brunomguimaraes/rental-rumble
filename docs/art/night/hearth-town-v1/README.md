# Hearth Town v1 — archived first draft

This is the superseded four-building, grassland-town direction. The owner clarified that Hearth Town
should instead be a functioning country community with public services, varied private homes, and no
tall grass. Use `../hearth-town-v2/` and `public/sprites/world/hearth-town-v2/` for the current direction.

The original three PNGs and initial overlay metadata are preserved in `assets/`; they are not served as
current game assets. `generation-prompts.json` records how the draft was produced with built-in imagegen.
